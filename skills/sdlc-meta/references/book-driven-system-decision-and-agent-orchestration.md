# Book-driven system decision and agent orchestration

This reference is an independent synthesis of durable principles from the supplied improvement, human-agent, business-system, supply-chain, finance, learning, and storytelling books.

## Whole-system engineering

Frame the aim, actors, constraints, measures, dependencies, capacity, failure modes, and decision horizon. Build and validate the actual baseline before proposing an optimised design. Use scenarios and sensitivity to expose brittle assumptions and second-order effects.

## Improvement and evidence

Run observe -> baseline -> select -> experiment -> check -> standardise -> teach -> re-measure. Treat a change as a reversible hypothesis with an owner, acceptance evidence, monitoring, and rollback. Do not locally optimise a component when the system outcome worsens.

## Agent operating contract

Define the agent's role, task boundary, tools, data access, autonomy dial, side-effect budget, approval gate, escalation rule, containment, recovery, audit trail, and postmortem loop. Increase autonomy only after reliability and safety evidence supports it. Preserve human control for consequential, ambiguous, or irreversible decisions.

## Currentness gate

Current AI, security, protocol, platform, library, and deployment claims must pass Digital Research source evaluation and verification. For AI risk claims, consult the current NIST AI RMF status; for application-security claims, consult the current OWASP ASVS; for other technology claims, use the relevant official primary source and record its review date.
