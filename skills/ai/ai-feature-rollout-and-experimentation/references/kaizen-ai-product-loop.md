# Kaizen AI Product Loop

Use for AI feature discovery, rollout, evaluation, and post-launch care.

1. Start with the user/system problem; compare AI with non-AI alternatives.
2. Map human actors, model(s), prompts, data, tools, policies, operations, affected non-users, and failure consequences.
3. Define user, model, business, safety, privacy, accessibility, and cost measures with guardrails.
4. Prototype with visible uncertainty, correction, undo, escalation, and human review.
5. Roll out reversibly: offline evaluation -> shadow -> supervised -> limited production -> wider release.
6. Monitor drift, data changes, feedback quality, incidents, subgroup performance, cost, and user trust.
7. Standardise the improvement only after independent review; log rejected hypotheses and update the model/system documentation.

The early-release *Designing for AI* material is a useful principle source, not a substitute for current legal or platform verification.
