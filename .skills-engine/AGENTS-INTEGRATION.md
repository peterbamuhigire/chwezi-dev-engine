# Universal agent integration

This engine remains independently usable. The universal coordination package may read this router, the documented skill glob, and the declared validation checks.

Missing files, dependencies, platforms, sources, or approval authority are NOT ASSESSED. No write, pull, publication, ledger, filing, deployment, or control change occurs without explicit approval and audit evidence.

The router and every domain SKILL.md remain authoritative. A fork may be inspected from its own checkout; no validator is invented when the engine is not catalogued.

MCP-safe tools are read-only discovery, router read, skill read, and documented-check inspection. Approval-required operations are not in the safe-tool list.
