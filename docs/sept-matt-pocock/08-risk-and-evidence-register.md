## Rejected direct imports

- The complete source repository as an additional active skill root. It would duplicate workflow
  capabilities, bypass local contracts, and compete for metadata budget.
- The source's `research` skill as a replacement for Digital Research.
- The source's HTML architecture-report scaffold as a design template.
- The Claude-specific Git regex hook as a portfolio safety control.
- Automatic issue creation, comments, labels, closes, assignment, or commits without action-specific
  authority.
- Hard-coded `gh`, `glab`, npm, Husky, Tailwind CDN, Mermaid CDN, or Bash behaviour in canonical
  cross-platform skills.
- Source beta and miscellaneous skills promoted merely because they exist.
- A second copy of spec ownership inside engineering; SRS remains canonical.
- Another bundled HTML email template collection.
