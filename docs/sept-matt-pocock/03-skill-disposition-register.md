# Skill Disposition Register

Legend:

- **Adopt**: a distinct Chwezi capability gap justifies an owned workflow.
- **Harden**: the capability already exists; add the source mechanism to that owner.
- **Reference**: retain as deep guidance, not a new active route.
- **Defer**: useful but not yet proven or not in the engineering portfolio's core scope.
- **Reject**: do not import; the mechanism is unsafe, redundant, too narrow, or vendor-bound.

## Net catalogue impact

Do not add every `Adopt` item immediately. Recommended first-wave active delta:

- Add `systematic-bug-diagnosis`: +1 active skill.
- Add either `codebase-design-and-deepening` or `domain-modeling`, not both in the same first wave:
  +1 active skill.
- Consolidate or alias at least two low-distinctness active skills before those additions.
- Land grilling, work-graph, invocation, handoff, review, prototype, merge, and wizard ideas as
  references/hardening first, with fixtures proving whether a later standalone route is justified.
